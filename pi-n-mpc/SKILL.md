# πⁿMPC 批量求解器

先读 [使用说明](使用说明.md)。包内 vendor/ 是作者开源的 PyTorch 和 JAX 内核，脚本用独立动力学与约束误差检查一个带限幅的双向跟踪问题。

1. 确认用户的目标是加速已有 MPC，还是新增 MPC 给训练提供参考。若已有求解器，保持被求解的问题一致，测量替换之后的收益。若新增参考，先定义参考怎么进入奖励、critic 或蒸馏。
2. 在接入前核对状态、控制、参考、坐标系、单位、预测步长和重算间隔。以源码的张量接口为准。公开版本要求共享 A，B 可随预测步和环境变化。先检查约束能否表示成现有投影所支持的上下界。
3. 用目标训练框架已有的后端。先运行小算例，核对动力学残差、越界量、目标函数、设备和张量形状。将新环境的建模与求解内核放在不同模块。
4. 对照相同的模型、接触约束和精度，分别计时准备与首次编译、预热后求解和整段训练。仅在完成目标环境实测后报告速度或策略质量的提升。
5. 若用户指 Walk the PLANC，原论文的质心参考由解析样条生成。可以把 πⁿMPC 接入为训练期参考消融，第一轮建议沿用原来的落脚目标和步时。用原样条作为对照。
