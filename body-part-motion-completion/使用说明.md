## 方法和使用条件

Humanoid-VLA §3.2 把动作分成左右腿、躯干、左右臂各一组，用遮挡输入和完整动作配对训练。这个包是该思想的独立最小实现，用连续关节角、时间窗口和岭回归补全一个组。已检查的论文与作者页面未提供对应训练源码，本包亦不含原论文的 VQ 码本、语言模型或机器人控制器。 [Humanoid-VLA §3.2](https://arxiv.org/html/2502.14795v1#S3.SS2) · [作者论文列表](https://dingpx.github.io/#publications)

- 输入是 NumPy .npz 文件，字段 motion 为 (片段数, 帧数, 关节数)。每个文件里的片段长度相同。主要用弧度表示关节角，训练和推理保持同一单位、轴顺序和采样率。
- 分组 JSON 至少包含两个非空组，每个关节索引恰好分到一个组。examples/toy-joints.json 是七维示例。实际索引应按目标机器人数据导出时的关节顺序生成。
- 需要完整轨迹作为监督。先按轨迹、地形或采集批次拆训练与验证，再切窗口，防止相邻重叠片段泄漏。用能够代表目标负载、步态和扰动的运动样本。数据中只有固定摆臂时，模型只会学到这一类标签。
- 当前一次填一个身体组，整个片段中该组的原值都被排除。其余组必须有效。推理时待补组可以是占位值或 NaN，输出保留可见组。多组同时缺失、跨机器人关节映射或四元数姿态要另作适配。
- 默认只用当前帧及过去两帧。离线重建可设置 --future 增加未来帧。因果窗口在片段开头复制首帧做边界填充。该模型输出是运动学参考，动力学可行性和控制收益仍需仿真验证。

## 局限

- 每次补全调用都把目标组在整个片段中的数值排除在输入之外。这一实现适合整组缺失的参考片段。若需要利用目标组中偶尔可用的帧、处理逐关节随机缺失或同时补全多个组，要另行设计缺失掩码和模型。
- 独立的线性模型只读取可见关节的时间窗口。可见动作相近时，缺失组可能因指令、接触对象或负载不同而采用不同动作。此时线性拟合可能给出几种动作的折中，换机器人、步态或任务时应重新验证。
- 输出是关节角估计。用于控制前须检查关节限位、速度、连续性，以及必要的碰撞和接触约束。补全误差和任务表现应分别评估。

## 快速运行

从本目录运行，Python 3.11 或 3.12，依赖只有 NumPy。可在无 GPU 的机器上训练和验证。

```powershell
python -m pip install -r requirements.txt
python scripts/complete_motion.py demo
```

合成示例在独立片段上检查缺失组误差、可见值不变、遮挡组占位值不影响输出，以及权重保存和加载。示例误差用于检查实现，实际机器人任务需用对应的数据另行评估。

用目标机器人的完整轨迹训练。下例将六轴机械臂靠近基座与靠近末端的关节分为两组。将分组保存为 `joint-groups.json`，索引按导出顺序填写，`--part` 使用分组文件里的名称。

~~~json
{"proximal": [0, 1, 2], "distal": [3, 4, 5]}
~~~

```powershell
python scripts/complete_motion.py train --motion train.npz --groups joint-groups.json --model completer.npz
python scripts/complete_motion.py complete --motion validation.npz --model completer.npz --part distal --out completed.npz --score
```

--score 需要完整验证真值，只对被补的关节统计 MAE。用于缺失数据推理时省略这个选项。输出 .npz 的 motion 与输入维度一致。作为 Python 模块使用时，入口是 scripts/body_mask.py 的 BodyPartCompleter.fit()、complete()、save()、load()，以及 mask_body_part()。

## 接入与评估

从仿真、示范或记录数据导出完整关节轨迹。先选一组作为补全目标，用实际可见的关节作为输入，并验证这些输入对目标组有预测价值。若更换机器人或重新分组，按新关节映射训练并评估模型。将结果用于预处理时，可在完整验证轨迹上遮挡目标组，和均值等简单基线比较误差。用于训练或控制时，另外检查任务成功率、平滑性与约束违例。

### 任务示例

- 单机械臂可用其余关节和时间窗口补全示范中缺失的一组关节参考。用关节误差验证补全效果，用末端跟踪误差评估下游影响。
- 双臂协同可把左右臂定义为不同组。用双臂存在配合关系的完整轨迹学习一侧对另一侧的预测能力，再用独立动作片段评估。

### Walk the PLANC

先由仿真中完整的 G1 rollouts 导出肩肘关节等实际动作、双腿、躯干及训练时本来可用的参考。以原步态和时序生成固定长度样本。保留原先的落脚、换脚时间和质心监督，让补全模型从相应的可见机器人轨迹生成手臂目标。第一轮只把它接到训练期手臂跟踪奖励，使用同一个学生 checkpoint 和同一套 curriculum 比较原相位摆臂。记录落脚误差、高差踏石通过率和外推扰动时躯干角速度。担心观测掉线时，应另外设计具有掉线模式的观测实验。 [PLANC 论文](https://arxiv.org/html/2601.06286v1#S3) · [训练入口](https://github.com/Zolkin1/robot_rl/blob/mlip/scripts/rsl_rl/train_policy.py#L8-L24)

可在轻量基线成立后换成 GRU 或其他时序模型。保持遮挡条件、监督轨迹和验证任务一致。若要学习跨组动作协调，可参考已有的物理仿真补全方法。 [MaskedMimic](https://arxiv.org/abs/2409.14393)
